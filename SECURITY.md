# Security policy

luna-pathway-frontend is used by patients to share health information, so we take security reports
seriously. Thank you for helping keep the project and its users safe.

## Reporting a vulnerability

**Please do not open a public issue, discussion or pull request for a security problem.**

Report it privately through GitHub instead:

1. Go to the repository's **Security** tab.
2. Click **Report a vulnerability**.
3. Fill in the form. Only the maintainers can see your report.

Please include:

- a description of the issue and its possible impact
- the steps to reproduce it (URL, browser, account type if relevant)
- any proof of concept, screenshots or logs — with personal data removed

## What to expect

- We aim to acknowledge your report within **5 business days**.
- We will keep you informed while we investigate and fix the issue.
- Once a fix is released, we are happy to credit you, unless you prefer to stay anonymous.

## Scope

This policy covers the code in this repository (the web frontend). Vulnerabilities in the Luna
backend API or in third-party services should still be reported through the form above; we will
forward them to the right team.

Please do not access, modify or delete data that does not belong to you, and do not run tests that
could disrupt the service for other users.
